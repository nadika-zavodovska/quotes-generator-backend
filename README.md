# Quotes Generator

A web application with Node.js and Express that provides and accepts inspirational quotes.

## Features
- Fetch a random quote
- Submit a new quote

## Tech Used
- HTML/CSS
- Node.js
- Express.js
- JavaScript

## Run Locally
```bash
git clone https://github.com/nadika-zavodovska/quotes-generator-backend.git
cd quotes-generator-backend
npm install
npm start
```
### Additional info 
- The backend will run at: http://localhost:3000
- Note: If you run the backend locally, update the frontend's URLs from the deployed Coolify address to http://localhost:3000 to ensure it works correctly.
